# Algebra

`Algebra` is a branch of mathematics that uses letters and symbols to represent unknown numbers and quantities.

Algebra allows us to build mathematical expressions representing
models.

<br/>

Key Parts of Algebra:

    - `Variables`: Letters like \(x\), \(y\), or \(z\) that stand for numbers we do not know yet.
    - `Constants`: Fixed numbers that do not change value.
    - `Equations`: Math sentences showing that two sides are equal, such as \(x + 3 = 7\)

<br/>

Why We Use Algebra:

    - `Solving Puzzles`: Finding the hidden value of a letter (if \(x + 2 = 5\), then \(x = 3\)).
    - `Real Life`: Figuring out costs, planning times, and measuring things.
