# Scalars

`A scalar is a single numeric value that can represent
magnitude but not direction.`

`Characteristics`: Scalars are used in many basic operations like
scaling vectors or defining thresholds. They are dimensionless and
have no orientation in space.

`Usage in AI`: Scalars are commonly used as weights, biases, loss
values, and activation thresholds. They control the scale or
influence of vector and matrix operations.

<br/>

**🏢 Real-World Examples**

🌡️ Temperature: \(27^{\circ }\text{C}\)
💵 Currency: \(\$12.50\)
⏱️ Speed: \(60\text{ mph}\)
⚖️ Mass: \(75\text{ kg}\)

<br/>

**🤖 AI / Machine Learning Examples**

📉 Learning Rate: \(0.01\)
⚖️ Model Bias: \(b = 0.5\)
🛑 Activation Threshold: \(0.0\) (as seen in ReLU)
📉 Loss Score: \(0.342\) (tracking training error)
